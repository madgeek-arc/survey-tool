# Changelog

All notable changes to survey-tool are documented here, newest first. Older entries were compiled from the Git history
between release tags (`feat`, `fix`, `refactor`/`perf`/`build` commits); chores, style and submodule bumps are omitted.

From now on this file is written by hand; there is no release tooling for it. Add a line under `## Unreleased` in the same
change that makes the user-visible change, under one of the headings Breaking changes, Added, Changed, Removed or Fixed. When
releasing, rename `Unreleased` to the version and date (for example `## 3.3.0 - 2026-07-01`) and tag that commit. The host
application's changelog is generated by release-please and is separate.
